# 台股除權息計算機

線上版：https://juitse1108.github.io/ex-dividend-calculator/

單檔靜態網頁，純前端計算，無任何外部依賴與網路請求。

## 解決什麼問題

除息很好算，除權不好算——尤其是**配股不足 1 股會被折成現金**這件事。
多數公司的畸零股按**面額 10 元**折現，高價股等於把那部分價值放掉。

工具算三件事：

1. **除權息參考價** `(收盤價 − 現金股利) ÷ (1 + 股票股利 ÷ 10)`，以及完全填權息所需漲幅
2. **你的持股會產生多少畸零股**、折現多少、跟按市價相比損失多少
3. **免畸零股的最小買進股數**，以及買不起時的次佳解

## 最小倍數怎麼算

配股率 = 股票股利 ÷ 10。把它化為最簡分數 `p/q`，持股數必須是 `q` 的倍數：

```
q = 10000 / gcd(股票股利 × 1000, 10000)
```

因為 10000 = 2⁴×5⁴，q 必定落在 {1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000, 10000}。

| 股票股利 | 最小倍數 |
|---|---|
| 10 元 | 1 股 |
| 5 元 | 2 股 |
| 2 元 | 5 股 |
| 1 元 | 10 股 |
| 0.5 元 | 20 股 |
| 19.842 元 | 5000 股 |

小數三位、尾數不含 2 或 5 的股利，最小倍數會衝到 5000 或 10000 股。

## 買不到最小倍數時

工具會列出帕累托前緣：每一列都是「在該股數以內殘餘最小」的紀錄點。
以 19.842 元為例，443 股的殘餘就只剩 0.0006 股，實質已可忽略，不必真的押到 5000 股。
